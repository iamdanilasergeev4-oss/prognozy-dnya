# Прогнозы дня

Сайт: https://prognozy-dnya.vercel.app — прогнозы на футбол, баскетбол, теннис, волейбол, CS2 и Dota 2, «Разбор дня» и история прогнозов с результатами.

## Методика v2

Прогнозы обновляет задание Claude по расписанию — утром и вечером. Сначала собираются данные (форма, составы, личные встречи, статистика вида спорта), затем делается вывод. Коэффициенты показываются только справочно и не считаются аргументом. В каждом прогнозе есть:
- `reason` — главный вывод;
- `facts` — 3–5 фактов с цифрами и источником;
- `against` — что говорит против;
- `uncertainty` — что может опрокинуть вывод;
- `data_quality` — насколько полные данные;
- `model_prob` — вероятность, только если её публикует названная модель.

## История прогнозов

Лежит в `data/history/` (файл на месяц даты матча; `index.json` — список месяцев и версии методики):
- прогноз записывается в момент публикации и потом не удаляется;
- правка до начала матча сохраняет прежнюю версию (`versions`), правка после начала отклоняется;
- прогноз, впервые опубликованный после начала матча, получает пометку `late` и не оценивается;
- результат записывается только по подтверждённому счёту. Если источники расходятся, ставится статус «требует проверки»;
- точность = подтвердившиеся / (подтвердившиеся + неподтвердившиеся). Возвраты, отмены, переносы и снятые прогнозы считаются отдельно.

## Код

- `index.html`, `app.js`, `style.css` — сайт (без сборки);
- `js/history-core.js` — логика истории (чистые функции), ею пользуются и сайт, и задание;
- `js/history-sync.js` — загрузка и подготовка файлов истории на странице github.com;
- `js/history-ui.js` — раздел «История прогнозов»;
- `api/suggest.js` — форма предложений → Telegram (переменные `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` в Vercel);
- `scripts/update.py` и `.github/workflows/update.yml` — запасной сборщик по старой методике v1 (Tavily + Gemini), запускается только вручную кнопкой Run workflow.

Тесты: `node --test tests/*.test.mjs` (Node 18+, без зависимостей).

Прогнозы не являются гарантией результата. 18+.
