# Прогнозы дня

Сайт: https://prognozy-dnya.vercel.app — прогнозы на футбол, баскетбол, теннис, волейбол, CS2 и Dota 2, «Разбор дня» и история прогнозов с результатами.

## Методика v2

До переноса проекта прогнозы обновляло задание Claude утром и вечером. В опубликованных прогнозах коэффициенты показываются справочно. Поля исторических прогнозов:
- `reason` — главный вывод;
- `facts` — 3–5 фактов с цифрами и источником;
- `against` — что говорит против;
- `uncertainty` — что может опрокинуть вывод;
- `data_quality` — насколько полные данные;
- `model_prob` — вероятность, только если её публикует названная модель.

## История прогнозов

Лежит в `data/history/` (файл на месяц даты матча; `index.json` — список месяцев и версии методики):
- прогноз записывается в момент публикации и потом не удаляется;
- правка до начала матча сохраняет прежнюю версию (`versions`), правка после начала отклоняется;
- прогноз, впервые опубликованный после начала матча, получает пометку `late` и не оценивается;
- результат записывается только по подтверждённому счёту. Если источники расходятся, ставится статус «требует проверки»;
- точность = подтвердившиеся / (подтвердившиеся + неподтвердившиеся). Возвраты, отмены, переносы и снятые прогнозы считаются отдельно.

## Код

- `index.html`, `app.js`, `style.css` — сайт (без сборки);
- `js/history-core.js` — логика истории (чистые функции), ею пользуются и сайт, и задание;
- `js/history-sync.js` — загрузка и подготовка файлов истории на странице github.com;
- `js/history-ui.js` — раздел «История прогнозов»;
- `api/suggest.js` — форма предложений → Telegram (переменные `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` в Vercel);
- `scripts/update.py` и `.github/workflows/update.yml` — запасной сборщик по старой методике v1 (Tavily + Gemini), запускается только вручную кнопкой Run workflow.

Тесты: `node --test tests/*.test.mjs` (Node 24, без зависимостей).

## Обновление по запросу

Напиши в Codex **«Обнови спортивную аналитику и покажи отчёт»**. Codex запустит сбор и сравнит семь категорий. В ответе будут события, доступность статистики, расчёты и причины пропусков. Дождись отчёта. Если подборка тебя устраивает, напиши **«Публикуй эту подборку»**. Код или команды для этого вводить не нужно.

Codex запускает `node scripts/update-sports.mjs --manual` из исследовательской ветки, сверив её файлы `data/` с актуальной `main`. Команда сохраняет исходные ответы и проверку в `.sports-update/manual-research/`, а отчёт `review.md`, подробности `diagnostic.json` и пробную копию сайта — в отдельном каталоге прогона. Численные оценки разрешены только в «Разборе дня» для прошедших историческую проверку футбольных лиг и при достаточной истории текущего сезона. Остальные пробные расчёты остаются в локальной диагностике.

После явного подтверждения Codex берёт свежую копию `main` и повторно проверяет согласованный пакет через `node scripts/update-sports.mjs --check-manual <каталог-прогона> <approvalId> <путь-к-копии-main>`. Проверка сверяет исходную и обновлённую версии данных, историю, срок актуальности и время матчей. Затем Codex переносит только перечисленные в пакете файлы `data/` и проверяет diff перед коммитом в `main`. После обновления GitHub Vercel разворачивает сайт, а `node scripts/update-sports.mjs --verify-deployment <путь-к-копии-main>` сверяет опубликованные данные с коммитом. При блокировке, изменении базы или устаревании отчёта нужен новый прогон и новое подтверждение.

## Техническая сверка расписания и результатов

`node scripts/update-sports.mjs --preview` (Node 24) собирает предстоящие матчи до конца завтрашнего дня по Москве и проверяет открытые записи истории. Результат, журнал ошибок и пробная копия данных сохраняются в `.sports-update/`. Рабочие файлы сайта при этом не меняются.

- В футболе, баскетболе и теннисе сверяются 365Scores и ESPN. Для хоккея также используется календарь NHL, для волейбола — Lega Pallavolo и TheSportsDB. CS2 сверяется по GosuGamers, Strafe и Ensigame, Dota 2 — по GosuGamers и Strafe. Охват лиг и глубина истории различаются. Два издателя могут опираться на один официальный протокол.
- В карточку попадают команды и время, которые удалось сопоставить по двум издателям. Если доступные данные не совпадают, карточка не публикуется. Система может добавить прогноз на победителя, если у обеих сторон есть достаточная сверенная выборка и виден перевес по форме. Для NHL также учитывается таблица сезона. Новый прогноз добавляется в историю с указанием методики и источников. Вывод по короткой выборке отмечается низкой уверенностью. Автоматические прогнозы публикуются без коэффициента и численной вероятности.
- В футболе остаётся до шести матчей с минимум двумя сверенными недавними результатами каждого участника. Для CS2 формат серии должен совпасть в двух источниках. Экспрессы составляются из уже опубликованных прогнозов на разные матчи. Для отбора проверяется перевес по результатам последних игр, а в NHL также допускается сверенный перевес по доле очков сезона, если недавние результаты его не опровергают. Отбор не оценивает вероятность выигрыша экспресса, а коэффициенты берутся из опубликованных записей.
- Сводка учитывает только прогнозы. В категориях без прогнозов показывается отдельное подтверждённое расписание со ссылками на источники. Расписание также доступно в теннисе, волейболе и Dota 2, когда прогноз составлен только на часть матчей. Для тенниса учитывается свежий рейтинг ESPN, для волейбольной Суперлиги сравниваются таблицы Lega Pallavolo и Volleyball World, для Dota 2 дополнительно используется Ensigame.
- До двух смешанных экспрессов составляются из новых прогнозов на разные виды спорта. При отсутствии опубликованных коэффициентов экспрессы показываются без общего коэффициента и не входят в денежную статистику. Их спортивный результат остаётся в истории.
- Команды и турниры CS2 и Dota 2 отображаются в оригинальном написании.

### Рынки прогнозов и расчёт

| Рынок | Данные и условия |
| --- | --- |
| Исход, двойной шанс, обе забьют | Исход сверяется по форме. Двойной шанс и «обе забьют» проверяются на исторических счетах футбольных матчей в основное время. |
| Общий тотал и фора | Для футбола, баскетбола и NHL берётся предматчевый порог, опубликованный ESPN с указанием DraftKings. Фора привязывается к конкретному участнику. Поддерживаются целые и половинные линии, равенство целой линии даёт возврат. |
| Тотал сетов или карт | Для матчей с известным BO3 и BO5 сравнивается количество сыгранных сетов или карт. Нужны сверенные полные счета подходящего формата. Такой порог описывает условие прогноза, цена рынка отдельно не проверяется. |
| Индивидуальные тоталы, геймы, раунды, периоды и статистика игроков | Индивидуальный тотал можно рассчитать при наличии явно заданной линии и счёта. Автоматический подбор этих рынков требует отдельных линий и статистики нужного периода или участника. |
| Азиатские четвертные линии, точный счёт, комбинированные и долгосрочные рынки | Нужны отдельные правила и данные. Четвертная фора делит расчёт на две соседние линии, возможны частичный выигрыш и возврат. Для угловых, карточек, эйсов, убийств и других показателей итогового счёта матча недостаточно. |

Для нового тотала или форы отбор требует по три сверенных счёта на каждого участника, минимум пять разных матчей в общей выборке и выполнение условия в обеих группах. Указанная доля относится к прошлым матчам. Данные о текущем составе и соперниках могут изменить вывод. В футболе используется основное время с компенсированным, в NBA и NHL — итог с учётом овертайма. Счёт незавершённой серии требует проверки. См. правила [футбола](https://sportsbook.draftkings.com/help/sport-rules/soccer), [хоккея](https://sportsbook.draftkings.com/es/help/sport-rules/hockey), [баскетбола](https://sportsbook.draftkings.com/help/how-to-bet/basketball-betting-guide) и [тенниса](https://sportsbook.draftkings.com/help/sport-rules/tennis).
- Архив сохраняется. История рассчитывается только при совпадении счёта, с учётом порядка команд и условий прогноза. Спорный счёт помечается «требует проверки». При недоступности обязательных источников или нарушении целостности истории публикация блокируется.
- `.github/workflows/sports-update.yml` также поддерживает ручной технический запуск с артефактом проверки. Для обновления через Codex используется процесс выше. Расписание GitHub оставлено выключенным.

Прогнозы не являются гарантией результата. 18+.
